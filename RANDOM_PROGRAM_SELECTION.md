# Random 2 Programming Questions

For an exam imported with 10 or more programming questions, the server selects
exactly TWO different programming questions for each student.

Selection key:
Student ID + Exam ID

The selection is deterministic:
- same student + same exam = same two programs after refresh/re-login
- different students get independently shuffled selections
- the original 10 programs remain stored in the exam
- the student's exam response contains only the selected two programs

For a 5-mark programming section, the selected two programs are 2.5 marks each.
